The cat command in Linux stands for Concatenate. It is one of the most commonly used commands for working with files in the terminal.

It is mainly used to:
- Display file contents.
- Create files and write content.
- Combine multiple files.
- Append content to existing files.
- Display line numbers.

# ==========================================
# LINUX CAT COMMAND - COMPLETE NOTES
# ==========================================

# 1. INTRODUCTION
# cat stands for Concatenate.
# It is used to:
# 1. Display file contents.
# 2. Create text files.
# 3. Append content to files.
# 4. Combine multiple files.
# 5. Display line numbers and special characters.

# 2. BASIC SYNTAX
cat [options] [filename]

# Example:
cat notes.txt
# Displays the contents of notes.txt.

# 3. DISPLAY FILE CONTENTS

# Display one file
cat file.txt

# Display multiple files
cat file1.txt file2.txt

# Display files with headings
echo "First file:"
cat file1.txt
echo "Second file:"
cat file2.txt

# 4. CREATE A FILE USING CAT

# Create a new file or overwrite an existing file
cat > notes.txt

# Type your content and press Ctrl + D to finish.
# Example content:
# Linux is an operating system.
# I am learning Linux commands.

# IMPORTANT:
# > overwrites existing content.

# 5. APPEND CONTENT TO A FILE

# Append new content without deleting old content
cat >> notes.txt

# Type your content and press Ctrl + D to finish.

# IMPORTANT:
# >> appends content at the end of the file.

# DIFFERENCE:
# >  = Create or overwrite a file.
# >> = Append content to a file.
# <  = Take input from a file.

# 6. IMPORTANT CAT COMMAND OPTIONS

# -n : Number all lines, including blank lines.
cat -n notes.txt

# -b : Number only non-empty lines.
cat -b notes.txt

# -s : Squeeze repeated blank lines into one.
cat -s notes.txt

# -E : Show $ at the end of each line.
cat -E notes.txt

# -T : Display tab characters as ^I.
cat -T notes.txt

# -A : Display tabs and other non-printing characters.
cat -A notes.txt

# -v : Display certain non-printing characters visibly.
cat -v notes.txt

# Combine options
cat -nE notes.txt

# 7. COMBINE MULTIPLE FILES

# Combine file1 and file2 into file3
cat file1.txt file2.txt > file3.txt

# Display the combined file
cat file3.txt

# Append another file to the combined file
cat file4.txt >> file3.txt

# 8. INPUT REDIRECTION

# Read input from a file
cat < notes.txt

# 9. USEFUL REAL-WORLD EXAMPLES

# Display system hosts file
cat /etc/hosts

# Display Linux user account information
cat /etc/passwd

# Display a configuration file
cat config.txt

# NOTE:
# Do not expose passwords, API keys, or secret environment variables
# in shared terminals or screenshots.

# 10. ALTERNATIVES TO CAT

# Display the entire file
cat file.txt

# Read a large file page by page
less file.txt

# Display one screen at a time
more file.txt

# Display first 10 lines
head file.txt

# Display last 10 lines
tail file.txt

# Display first 5 lines
head -n 5 file.txt

# Display last 5 lines
tail -n 5 file.txt

# 11. PRACTICAL HANDS-ON EXERCISE

# Create a directory
mkdir cat_practice

# Enter the directory
cd cat_practice

# Create first file
cat > linux.txt

# Enter:
# Linux is an open-source operating system.
# Linux is used by developers.
# I am learning Linux commands.

# Press Ctrl + D.

# Display file
cat linux.txt

# Display with line numbers
cat -n linux.txt

# Append new content
cat >> linux.txt

# Enter:
# The cat command displays file contents.

# Press Ctrl + D.

# Create second file
cat > commands.txt

# Enter:
# ls
# pwd
# mkdir
# touch

# Press Ctrl + D.

# Combine both files
cat linux.txt commands.txt > final.txt

# Display final file
cat -n final.txt

# 12. QUICK REVISION

# cat          = Display file contents
# cat -n       = Number all lines
# cat -b       = Number non-empty lines
# cat -s       = Squeeze repeated blank lines
# cat -E       = Show line endings
# cat -T       = Show tab characters
# cat -A       = Show non-printing characters
# cat > file   = Create or overwrite file
# cat >> file  = Append content
# cat < file   = Read input from file
# cat a b > c  = Combine files a and b into c

# 13. IMPORTANT INTERVIEW POINTS

# Q1. What is cat?
# Ans: cat stands for Concatenate. It displays and combines files.

# Q2. How do you create a file using cat?
# Ans: cat > filename

# Q3. How do you append content?
# Ans: cat >> filename

# Q4. Difference between > and >>?
# Ans: > overwrites; >> appends.

# Q5. Which option numbers all lines?
# Ans: -n

# Q6. Which option numbers only non-empty lines?
# Ans: -b

# Q7. How do you combine two files?
# Ans: cat file1 file2 > file3

# Q8. Which command is better for large files?
# Ans: less

# 14. IMPORTANT REMINDERS

# 1. Press Ctrl + D to finish entering content with cat > or cat >>.
# 2. Be careful: > overwrites existing file contents.
# 3. Use >> when you want to preserve existing contents.
# 4. Use less for large files.
# 5. Avoid using cat to display binary files.
# 6. Be careful when displaying files containing sensitive information.
